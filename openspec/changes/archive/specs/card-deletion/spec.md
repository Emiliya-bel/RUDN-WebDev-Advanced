# Delta Spec: card-deletion

## ADDED Requirements

### Requirement: Элемент управления для удаления
Каждая карточка на доске должна иметь визуальный элемент (иконку корзины), при клике на который инициируется процесс удаления.

#### Scenario: Клик по кнопке удаления
- **WHEN** пользователь кликает по кнопке удаления на карточке
- **THEN** появляется диалоговое окно с подтверждением действия.

### Requirement: Удаление с сервера
При подтверждении удаления клиент должен отправить запрос на сервер для безвозвратного удаления карточки из базы данных.

#### Scenario: Успешное удаление
- **WHEN** пользователь подтверждает удаление
- **THEN** клиент отправляет DELETE-запрос
- **AND** сервер возвращает успешный статус
- **AND** карточка исчезает с доски без перезагрузки страницы.

#### Scenario: Отмена удаления
- **WHEN** пользователь отменяет удаление в диалоговом окне
- **THEN** карточка остаётся на доске, запрос на сервер не отправляется.
