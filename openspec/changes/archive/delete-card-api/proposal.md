# Proposal: Исправление удаления карточек через API

## Проблема
После переезда на реальный сервер удаление карточек сломалось. Кнопка на клиенте отправляет DELETE-запрос на `/api/cards/:id`, но сервер отвечает 404, так как не имеет соответствующего маршрута. Кроме того, при ошибках сервер возвращает HTML-страницы вместо JSON, из-за чего клиент не может корректно обработать ответ.

## Решение
Настроить серверный роутинг так, чтобы он принимал запросы по пути `/cards/:id`. Добавить глобальные обработчики для неизвестных путей (404) и внутренних ошибок (500), которые будут возвращать ответы в формате JSON. Код клиента менять запрещено.

## Затрагиваемые способности (Capabilities)
- `card-deletion-api`: корректная обработка сервером DELETE-запросов на удаление карточек и возврат JSON при любых ошибках.
