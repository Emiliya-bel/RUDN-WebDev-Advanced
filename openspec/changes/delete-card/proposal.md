# Proposal: Удаление карточки

## Проблема
На доске нет способа убрать карточку — ни ошибочно созданную, ни просто ненужную. Один раз добавленная карточка остаётся навсегда.

## Решение
Добавить элемент управления (кнопку) на каждую карточку, который позволит пользователю удалить её. Удаление должно отправлять запрос на сервер и мгновенно обновлять интерфейс без перезагрузки страницы.

## Затрагиваемые способности (Capabilities)
- `card-deletion`: способность удалять карточки с доски.

## Подтверждение перед удалением
Пользователь может нажать кнопку случайно. Поэтому перед отправкой запроса необходимо показать диалоговое окно подтверждения.
