# Delta Spec: card-deletion-api

## ADDED Requirements

### Requirement: Удаление карточки по ID из пути
Сервер должен принимать DELETE-запросы на адрес `/cards/:id`, где `:id` — это идентификатор карточки. ID должен извлекаться из параметров пути (`req.params`), а не из тела запроса.

#### Scenario: Успешное удаление
- **WHEN** клиент отправляет DELETE-запрос на `/cards/:id`
- **THEN** сервер удаляет карточку
- **AND** возвращает статус **200 OK** (выбрано как стандарт для успешного выполнения без тела ответа).

#### Scenario: Удаление несуществующей карточки
- **WHEN** клиент отправляет DELETE-запрос с несуществующим `id`
- **THEN** сервер возвращает статус **404 Not Found**
- **AND** JSON с сообщением об ошибке (например, `{"error": "Card not found"}`).

### Requirement: Обработка ошибок
Сервер не должен возвращать HTML-страницы при ошибках. Все ошибки должны быть в формате JSON.

#### Scenario: Неизвестный маршрут (404)
- **WHEN** пользователь переходит по несуществующему адресу (например, `/no-such-path`)
- **THEN** сервер возвращает статус **404 Not Found** и JSON с описанием ошибки.

#### Scenario: Внутренняя ошибка сервера (500)
- **WHEN** в сервере происходит непредвиденная ошибка (например, при вызове `next(err)`)
- **THEN** сервер возвращает статус **500 Internal Server Error** и JSON с описанием ошибки.
